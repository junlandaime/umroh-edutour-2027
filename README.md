## 🏛 7 Destinasi Edutour & Rihlah Ilmiah
1. 🔬 **KAUST (King Abdullah Univ. of Science & Technology) Thuwal:** Tur Core Labs, Superkomputer Shaheen, riset energi & kupas tuntas KAUST Fellowship (Beasiswa S2/S3).
2. 🏛 **Education City & QNL Doha:** Konsorsium kampus Ivy League (Texas A&M, CMU, Georgetown) & perpustakaan digital termodern dunia karya Rem Koolhaas.
3. 🤝 **Jejaring Diaspora Alumni ITB di Qatar:** Sharing session karier teknologi & energi bersama profesional IA-ITB Qatar.
4. 🏛 **Umm Al-Qura University Makkah:** Studi peradaban Islam, syariah & arsitektur kota suci.
5. 📜 **Museum Wahyu (Hira Cultural District):** Eksplorasi sains-sejarah Al-Qur'an pertama di Gua Hira (Jabal Nur).
6. 🚅 **Teknologi Kereta Cepat Haramain (300 km/jam):** Uji mobilitas kereta peluru gurun Talgo 350 Spanyol lintas Makkah-Madinah.
7. 🎓 **Islamic University of Madinah (UIM) & Sharing Prof. Nid:** Kunjungan kampus internasional, perpustakaan manuskrip & sharing session Diaspora Guru Besar ITB di Madinah.

## 🚀 Cara Mengaktifkan GitHub Pages
1. Pastikan repositori berstatus **Public**.
2. Masuk ke tab **Settings** di repositori GitHub Anda.
3. Klik menu **Pages** di sidebar kiri.
4. Pada bagian **Build and deployment**:
   - **Source:** *Deploy from a branch*
   - **Branch:** `main` / folder `/ (root)`
   - Klik **Save**.
5. Tunggu sekitar 1–2 menit, web akan aktif di:  
   `https://junlandaime.github.io/umroh-edutour-2027/`
